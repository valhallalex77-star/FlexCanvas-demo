FlexCanvas

FlexCanvas is a spatial window container and workspace management system for Windows. It hosts real external application windows inside a unified canvas, preserving native interaction while allowing free arrangement, snapping, and window switching.

Unlike screenshot-based solutions, FlexCanvas works with real Windows HWNDs. It does not fake application content using screenshots, DWM thumbnails, or video streams.

View Source Code Compatibility Matrix

Project status: S0–S3 implemented and verified. Workspace persistence (S4) and release hardening (S5) are not implemented yet.

Highlights

Real HWND Embedding

Embeds external windows using Win32 SetParent, preserving the information needed to restore their original state.

Safe Recovery

Stores rollback snapshots, supports retry after failures, and does not terminate hosted applications when FlexCanvas closes.

Spatial Canvas

Provides a 4096 × 4096 DIP canvas with geometry overview and native 1:1 window interaction modes.

Snapping Engine

Supports edge alignment, seamless adjacency, and equal-gap snapping with a strict 12 DIP threshold.

Explicit Resize Behavior

Only explicit user actions change a hosted window's real size; external size changes synchronize with the layout.

Non-Fullscreen Focus

Selecting a container raises its host in the Z order without maximizing it or moving other windows.

Compatibility Boundary

  • The target must be a top-level window using matching Per-Monitor V2 DPI awareness.
  • The target and FlexCanvas must run at the same privilege/integrity level.

Unsupported windows are rejected with errors such as DPI_MISMATCH or ACCESS_DENIED. FlexCanvas does not inject code, bypass UIPI, elevate itself, or kill external processes.

Architecture

FlexCanvas.Application      View models and embedding orchestration
FlexCanvas.Domain           Layout, snapping, geometry, state machines
FlexCanvas.Infrastructure   Win32 APIs, embedding, discovery, diagnostics

Requirements

  • Windows 10/11 x64
  • .NET SDK 8.0.426, pinned by global.json
  • An interactive desktop session for tests that launch real windows

Build and Test

dotnet restore FlexCanvas.sln
dotnet build FlexCanvas.sln -c Release
dotnet test FlexCanvas.sln -c Release --filter "Category!=NativeIntegration"

Run the full suite, including native integration tests, with:

dotnet test FlexCanvas.sln -c Release

Run

dotnet run --project src\FlexCanvas.App\FlexCanvas.App.csproj -c Release --no-build
  1. Open Window Discovery, refresh, and select a target window.
  2. Click Check Selected Window to review compatibility.
  3. Use Embed Selected Window or Embed to Canvas (1:1).
  4. Use Spatial Canvas to arrange windows in overview mode and interact in native 1:1 mode.
  5. Close FlexCanvas normally to restore hosted windows.

FlexCanvas 是一款面向 Windows 的空间窗口容器与工作区管理系统。它将外部应用程序的真实窗口嵌入统一画布，在保留原生交互能力的同时，支持自由排列、吸附和窗口切换。

FlexCanvas 操作的是真实 Windows HWND 窗口，不会使用截图、DWM 缩略图或视频流伪造应用内容。

核心特性

真实 HWND 嵌入

通过 Win32 SetParent 嵌入外部窗口，并保存恢复窗口原始状态所需的信息。

安全恢复

保存回滚快照，失败时支持重试；关闭 FlexCanvas 不会终止被托管的应用程序。

空间画布

提供 4096 × 4096 DIP 画布，包含几何概览和原生 1:1 窗口交互模式。

吸附引擎

支持边缘对齐、无缝相邻和等间距吸附，严格阈值为 12 DIP。

明确的缩放行为

只有用户显式操作才会改变窗口实际尺寸；外部尺寸变化会同步到布局。

非全屏聚焦

选中容器时提升宿主窗口的 Z 顺序，不会最大化窗口或移动其他窗口。

兼容性限制

  • 目标必须是顶层窗口，并使用与宿主匹配的 Per-Monitor V2 DPI 感知模式。
  • 目标应用与 FlexCanvas 必须运行在相同的权限/完整性级别。

不符合条件的窗口会返回 DPI_MISMATCH 或 ACCESS_DENIED 等错误。FlexCanvas 不会注入代码、绕过 UIPI、提升自身权限或终止外部进程。

运行

dotnet run --project src\FlexCanvas.App\FlexCanvas.App.csproj -c Release --no-build
  1. 打开 Window Discovery，刷新并选择目标窗口。
  2. 点击 Check Selected Window，查看兼容性检查结果。
  3. 使用 Embed Selected Window 或 Embed to Canvas (1:1) 嵌入窗口。
  4. 进入 Spatial Canvas，在概览模式中排列窗口，在原生 1:1 模式中进行交互。
  5. 正常关闭 FlexCanvas，恢复被托管的窗口。
