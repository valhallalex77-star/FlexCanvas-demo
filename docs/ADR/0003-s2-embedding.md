# ADR 0003：S2 正式承载与安全恢复

日期：2026-10-16。范围：T0501-T0503/T0601-T0602。S1 退出来自用户全部测试确认，原始自动化证据不扩大。

- 正式承载接口与 POC 分离；保留 POC 代码/工具/测试，不把白名单 POC 当生产服务。
- 对用户明确选定并再次确认的顶层目标操作。系统/自身/owner/子窗口/危险样式/隐藏/最小化/不同 DPI awareness 或权限不明均拒绝。重新读取 elevation、integrity、UIAccess、进程创建时间；同权限不是第三方兼容保证。
- 运行期会话以 Guid + HWND/PID/进程创建时间标识，保存 parent/style/exstyle/物理矩形/placement/DPI。各原生调用前再验证目标，仍不能彻底消除同进程 HWND 复用和 TOCTOU。
- 专用 STA 串行执行；修改开始前标记需恢复；嵌入失败回滚，回滚/解除失败保留会话与宿主，支持重试。尺寸操作不自动抢焦点；点击“聚焦”才有限 AttachThreadInput/SetFocus，finally 成对解除，不使用注入、全局键盘钩子或强杀。
- 简单独立承载窗口用于 S2 输入/尺寸/解除验证，不开发 S3 画布。主窗口关闭逐个解除，任何失败阻止退出。正常关闭不结束目标进程。
- WinEventHook out-of-context：回调只采集并排队，串行消费者复核会话代次与身份，忽略重复/迟到事件；成对解除。销毁通知不是身份失效的证明。活动会话状态查询作为漏事件兜底，不扫桌面。
- 全部自动化只操作本次自建 Probe；人工第三方嵌入需界面确认。只宣称测试过的应用/配置支持；权限/DPI/IME/崩溃仍逐项留证，CLR/强制 Host 崩溃的最佳努力恢复不能保证。
- 回退：正常 Detach 恢复；失败保留宿主供重试。不自动初始化 Git/提交/删除用户数据；无版本恢复点。

实施检查点：Release 0 警告/错误，62 项测试与 S1/S2 UI Smoke 通过，完整证据见 [S2 报告](../S2_REPORT.md)。真实键盘/IME/权限/DPI/崩溃与恢复失败 UI 未整组验收，S2 不退出。

恢复校验说明：SetParent(NULL) 时仍带 WS_CHILD，GetParent 中间态可报告桌面。保留返回值/立即错误码检查，将顶层 parent 精确校验放在原样式恢复之后；不放宽最终样式/矩形断言。

2026-10-19 阶段更新：用户确认“S2验证完毕可以退出，现在开始任务S3”，接受 S2 完整验收与退出；上方“不退出”为初次检查点历史。未附逐场景日志，不扩大助手亲测范围；安全恢复策略、兼容限制、公共 API 注释及原生错误覆盖债务保持不变。S3 需另行确认画布/原生 HWND 缩放设计，不改变此 ADR 的恢复约束。
