# ADR 0001：S0 最小骨架与受控 HWND POC

日期：2026-10-16。状态：本次 S0 实施决策；不冻结生产服务接口。

## 范围与依据

用户选择“完整 S0 POC”。按初稿§1.8、§4、§8、§11.2、§13.1及 TASKS.md T0101-T0202，建立最小分层工程、独立 Host、Win32/WPF/WinForms Probe、原生验证和测试；不进入 S1 的完整启动编排、全桌面窗口发现或画布/工作区开发。

## 决策与理由

1. Q01：S0 建立四层项目和独立验证工具；正式 App 只是明确标识未实现业务的 WPF 空壳。完整产品必须在 S0 退出门槛通过后再获授权。
2. Q03：Domain 定义 POC 专用结果、物理像素快照与完整状态词汇；Application 只定义原生端口；Infrastructure 集中 P/Invoke、可回滚引擎与 STA Dispatcher。View 不声明原生 API。结果保留稳定代码、消息和即时 Win32 错误；生产接口留待后续确认。
3. 同一会话的原生操作在专用 STA 消息泵串行执行，UI 仅异步调用。取消仅在操作开始前生效，不能在修改与回滚中途丢弃快照。同步的跨进程原生调用仍可能因目标挂起而拖延，POC 不承诺任意进程超时恢复。
4. 仅允许从本仓库 `tools` 下构建、进程名匹配的自制 Probe。不操作用户的记事本/浏览器等现有窗口。宿主必须属于当前进程，目标必须属于另一进程且为可见、非最小化、无 owner 的顶层窗口。
5. 显式检查权限/elevation 与 DPI awareness；拒绝未知/不同权限和不同 awareness。WPF/原生 Probe 使用 asInvoker + PerMonitorV2 Manifest，WinForms 使用仅 asInvoker Manifest 并在入口通过 SetHighDpiMode 配置 PerMonitorV2，避免 WFAC010 冲突。专用线程逐操作设置/恢复 DPI 上下文，不提权、不改系统 DPI。跨屏混合 DPI 和更广应用支持仍需实测，不能由初筛推出兼容结论。
6. 先快照父窗口、样式/扩展样式、矩形、PID和DPI，再调整 CHILD/POPUP/边框及 SetParent。任一步失败最佳努力恢复；恢复失败保留会话供重试，关闭 Host 时不静默丢弃失败，不默认关闭外部应用。
7. Q07：锁定已安装 SDK 8.0.426（仅允许同 feature band 补丁滚动），使用 nullable、x64、警告作为错误。测试包采用 .NET 8 可用的 xUnit 2.9.3、runner 2.8.2、Microsoft.NET.Test.Sdk 17.11.1，由中央配置维护。无 MVVM/DI/日志框架或 Mock 包；测试使用明确标注的 fake 原生端口，不能代表真实兼容。
8. 初版 POC 用按需 Probe 枚举和每秒一次的活动会话健康检查，不做高频桌面扫描。真正的事件钩子、同进程 HWND 复用强化、生产生命周期服务留在 T0601；此限制必须记入报告。
9. POC 诊断只保留有限 UI 日志，用户显式导出到本地日志目录；不记录输入文本、完整无关路径、不上传。滚动日志与生产异常策略留在 T1201。

Q02/Q04-Q10 中与完整产品相关的歧义不在 S0 自行定案。3 次原生循环是本次可重复验证样本，不是生产耐久阈值；不测就不宣称性能/资源/兼容性通过。

## 验证与回退

- 骨架：实际 restore/build、分层引用测试、状态机与结果测试。
- 受控承载：fake 端口验证失败/回滚/重试；真实 Probe 验证嵌入、移动/尺寸、原始父窗口/样式/矩形恢复以及进程仍存活。
- POC-2 输入/IME/菜单/弹窗、POC-3 多 DPI/多屏/睡眠与 POC-4 真正崩溃/权限差异不能用 fake 或构建代替，分别记录未测试/失败/通过。
- 安全回退先解除当前 Probe，不自动杀进程。未初始化 Git、不提交，源文件修改清单不等于恢复快照；不自动删除原稿、用户目录或依赖配置。
- 实测证据见 `docs/S0_POC_REPORT.md`，以文件存在和实际命令结果为准；未完成退出条件时停在 S0，不开始完整画布。
